# Receipt Price Challenge (เกมคิดราคาสินค้าจากใบเสร็จ) - WebGL

เกมฝึกสมองคำนวณราคาสินค้าจากใบเสร็จ (Receipt Calculation Game) พัฒนาด้วย Unity WebGL ออกแบบสำหรับหน้าจอมือถือแนวตั้ง (Portrait Responsive)

## 🎮 ฟีเจอร์หลักในเกม
- 🧾 **อนิเมชั่นพิมพ์ใบเสร็จ**: จำลองการพิมพ์ใบเสร็จจากเครื่องพิมพ์และลอยเข้าหาหน้ากล้อง
- 🍎 **ร้านขายผลไม้คุณเอ๋**: ระบบสุ่มรายการผลไม้และราคา
- ⏱️ **10 Levels x 3 Rounds**: ไต่ระดับความยากตั้งแต่ Beginner ถึง Advance พร้อมคิด % ส่วนลด
- 📊 **Summary & Star Rating**: หน้ารายงานสรุปผล performance คะแนนและดาวหลังเล่นจบ 10 ด่าน
- 📱 **Mobile Responsive**: รองรับหน้าจอมือถือทุกรุ่น (iOS & Android)

## 🚀 วิธีเปิดเล่นบน Local Web Server
```powershell
python -m http.server 8080
```
เข้าผ่าน Browser: `http://localhost:8080`
